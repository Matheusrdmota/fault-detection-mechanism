## Towards an Unsupervised Fault Detection Mechanism in Microservices

# 🚀 About

    This project implements a fault detection system for microservices using unsupervised Machine Learning techniques based on system collected metrics.

## 📦 Installing


```bash
git clone https://github.com/seu-usuario/seu-projeto.git
cd seu-projeto
```

Crie e ative um ambiente virtual:

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
```

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ How to start

On the root dir:

```bash
python -m src.main
```
